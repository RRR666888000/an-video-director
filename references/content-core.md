# 内容判断：先找观看的动力


## 一条视频的决策卡

内部用几句话定清楚即可；复杂或协作任务再交付表格。

| 决策 | 要落到什么程度 |
|---|---|
| 本条作用 | 轻种草/进房咨询/直接下单/认识人物/理解知识/感受生活时刻，选主要作用 |
| 观众当下 | 处在什么情境，已知什么，想要什么，愿意付多少理解成本 |
| 核心承诺 | 会看到什么变化，得到什么体验或答案 |
| 材料依据 | 哪个原声、动作、实物或事件能支撑，不替素材编答案 |
| 持续动力 | 看完这一句为什么还愿意看下一句 |
| 落点 | 视频交付什么，下一步还值得了解什么，不硬留所有答案 |

不要只写“增加信任”。例如展示同一件实物的实际操作，让人看见讲解依据；这支持理解操作，不自动证明耐用性或长期效果。

## 钩子：对什么人有效


- 与我相关：特定人群、处境或正在做的选择。
- 正向体验：好看的成品、真实动作、值得拥有的状态。
- 认知差异：外表相似但存在有意义的差别；要有真实依据。
- 人物事件：欲望、正在发生的事、自然表情、不寻常关系。
- 具体问题：观众真想知道答案，而非创作者觉得知识重要。

优先从材料找钩子，不先写惊人标题再逼素材配合。开头可以是画面、声音或组合，不一定是问题句。判断是否吸引目标人群，而不只是否刺激。后加标题不能假称原话。

## 骨架：五种持续动力


| 动力 | 成立条件 | 常见失败 | 剪辑动作 |
|---|---|---|---|
| 兴趣点推进 | 后面有新的、有价值的信息 | 同一特点反复换说法 | 合并重复，每段新增信息 |
| 戏剧性推进 | 欲望、障碍、行动与结果 | 流水账或悬念不兑现 | 保留改变局面的节点 |
| 共鸣推进 | 具体处境与感受能被认出 | 空泛金句、强行煽情 | 保留有辨识度的细节和反应 |
| 理性逻辑推进 | 观众先想知道答案 | 未建立问题就讲原理 | 问题→依据→结论，必要前提不删 |
| 节奏推进 | 视听本身有吸引力和变化 | 只有快切、机械卡点 | 动作、声音、重复与差异构成体验 |

每段都问是否推进核心承诺。不强相关的信息，即使好看，也可能分散注意。并列信息要安排新旧、难易、强弱，不能平铺卖点。

## 情绪与理解负荷


情绪刺点可出现在任意位置，也可与钩子重合。惊讶、认同、喜欢、心疼、想试一试都可能是反应，不必安排争议或反转，不是每条都要喊、哭、搞笑。

区分**有效信息**与**理解负荷**：前者是用户得到的具体发现和感受；后者是抽象词、陌生名词、长句、多主线带来的难度。原课“信息密度”的讨论也涉及理解负荷，不能概括成密度越高越好。

字多、镜头快不等于有效。画面能说明就少用抽象语言重复；陌生原料名后跟可理解的感官描述；复杂信息留识别时间。快慢、详略、停顿服务理解与体验。

## 素材拆解与计数

候选窗口记录：来源/时间、原声意思、可见动作、在视频中的作用、限制、可搭配段。转写时间只作选窗，最后切点需复核。

可分：开头、需求/场景、特点、体验/证明、顾虑、结尾、气氛与过场；一个片段可承担多个作用。

- 独立方向：不同观看/购买动机，有足够素材形成完整表达。
- 版本：同主体换钩子、人群、证据或结尾。
- 模块：近景、材质细节、使用动作本身，通常不是独立创意。

缺口具体到功能，例如“缺一段同款实际使用时的连续动作”。证据不足的方向留作补拍，不算现有材料已经能剪出。
