# 商业内容：视频和后续场景各做什么


## 目的地决定结构深度

| 类型 | 视频完成什么 | 后续承接 | 不要混用的标准 |
|---|---|---|---|
| 千川/直播引流 | 筛选兴趣、轻种草、具体问题或期待 | 直播展示、选款、解惑、交易 | 不要求一条视频完成全部购买说服，也不把泛好奇当成交 |
| 挂车直接带货 | 为什么需要、关键证明、如何买 | 商品页与履约 | 关键顾虑未解决不能只靠点链接 |
| 人设/品牌 | 稳定的表达、行动、价值带来认识 | 其他内容或直播 | 不强迫每条直接卖货 |
| 本地获客 | 对本地特定需求的真实价值 | 到店、预约、咨询 | 地址、营业状态、服务承诺须可兑现 |

复杂、需要试选或信任的商品，直播承接可能更重要。课程客单价举例不是固定价格分界线。

## 从特点到想拥有


用“情境—体验—依据—用户意义”推导。以假设的收纳袋素材为例：
- “分区多”是特点。
- “通勤时不用翻整包就能取出钥匙”是情境中的体验，需真实操作支撑。
- “这能解决我每天找东西的麻烦”是希望激发的兴趣，仍待测试。

先找素材中真实的体验、顾虑。痛点、爽点、痒点、时效是找需求的视角，不是强制标签，也不授权虚构焦虑或效果。

## 两条引流路径

**产品兴趣**：具体产品/体验吸引 → 动作与描述支撑 → 商品记忆 → 到直播间看这款、问这款。允许轻种草，不必证明全部优点。

**选择咨询**：具体选择问题 → 为什么不好选 → 实际产品举例 → 直播能帮助解决什么。进房价值来自展示与推荐，不是故意把问题讲不清楚。

片尾顺着前面的兴趣。前面讲具体一款，结尾突然泛说“帮你选款”可能带散兴趣；前面讲选择，结尾谈偏好就更自然。没有自然口播时可用字幕，不硬拼原声。

看完、点击、进房、购买分别判断。解释创意用“希望/要验证”，不声称一定来买。

## 按现有素材选择商业表达


| 类型 | 适用材料 | 剪辑重点 / 证据边界 |
|---|---|---|
| 卖点快切 | 多个互补卖点与演示 | 按欲望强弱和理解顺序排列；重复就缩成体验片 |
| 素人日常种草 | 自然使用与生活感受 | 保留动作表情；主播可分享自用，不伪装买家 |
| 知识创造需求 | 会影响选择的知识 | 问题先于原理，知识连接实际价值；冷知识不自动产生购买欲 |
| 情境营销 | 可认出的使用处境 | 让人想象自己使用；缺生活镜头就列补拍 |
| 情境加人设故事 | 真实人物、处境、选择 | 产品进入行动，不当生硬贴片；无事件可改分享 |
| 序言式故事 | 可快速交代并引出主题的事 | 小故事建立问题，主体兑现；影视不能证明实际产品效果 |
| 福利营销 | 真实有效的当前活动 | 谁能得、得什么、如何得；旧券、期限、排名先核实 |
| 娱乐剧情 | 完整喜剧/反差/互动 | 梗与产品有关，笑点后记得对象；单个表情不算完整剧情 |

## 证明和顾虑


近景说明可见质地；动作说明怎么用；口述体验表达讲述者感受；原料展示辅助解释材料说法。它们不能自动替代检测、效果试验或买家评价。重组不能扩大证据能力。

顾虑可能是个人偏好、复杂程度、时间、试错、信任，未必只有价格。先解决影响当前一步的顾虑，不在20秒里塞完全部成交环节。售后、活动、库存、配方版本读取当前依据。

## 专业服务工作室：从理解到合适咨询

以下为本Skill结合服务场景的操作设计。设计、摄影等服务的咨询可能经过多次观看；不能仅凭一条片当天没有咨询判定失败，也不能默认陌生老粉需要该服务。

让观众理解：服务哪类问题，怎样作判断与交付，适合什么合作条件。用可公开的真实过程、方案取舍和交付物作依据；没有客户结果时不编造案例或保证收益。人物内容可展示本人判断，服务内容补充具体解决的问题，不要求每条日常都邀约。

“有效咨询”依本次服务范围定义，如需求类型、项目阶段、时间/预算是否有基本匹配；不把所有留言或私信都算有效线索。用户未给服务范围，先标为待定义，不默认索取客户隐私。比较咨询数量时同时看匹配度及后续进展，时间窗口和触达条件不同需注明。

内容审视先看观众能否回答“你能帮我什么、凭什么适合、如何进一步了解”；再核对实际咨询入口和承接资料。没有作品只能列排查假设，没有数据不能判断触达或转化。提出沟通建议不等于替用户发送邀约或回复客户。

## 商家内容体系与验收


视频兴趣要有直播能接住的实物、讲解与选购路径。商家未必先成为泛娱乐博主；根据业务判断新增认识、信任、交易的内容分工，不套历史预算比例。

内容验收：吸引谁？记住什么对象？进来要看什么/问什么？直播能否承接？实际效果按 [实验与复盘](testing.md) 分层分析。
